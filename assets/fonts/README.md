# Ring brand fonts

These are the teamofsilicons.com typefaces. All are licensed under the SIL Open Font License 1.1, so they can be bundled in every Ring client. The `.woff2` files are the web originals. The `.ttf` files were converted with fontTools for native platforms, which can't load WOFF2.

| Family | Use | Files | PostScript names |
|---|---|---|---|
| BDO Grotesk | UI and body text | `bdo-grotesk/BDOGrotesk-{Regular,Medium,Bold,Black}` | `BDOGrotesk-Regular`, `BDOGrotesk-Medium`, `BDOGrotesk-Bold`, `BDOGrotesk-Black` |
| Hedvig Letters Serif | Display: people's names on call screens and page titles | `hedvig-letters-serif/HedvigLettersSerif-Regular` | `HedvigLettersSerif24pt24pt-Regular` (family "Hedvig Letters Serif 24pt") |
| Geist Pixel Square | The "RING" wordmark, small uppercase labels, badges, timers | `geist-pixel/GeistPixel-Square` | `GeistPixel-Square` |
| Geist Pixel Grid | Large display numerals (optional) | `geist-pixel/GeistPixel-Grid` | `GeistPixel-Grid` |

Geist Pixel is © 2023 Vercel with basement.studio (`geist-pixel/LICENSE.txt`). BDO Grotesk is by VJ Type, and Hedvig Letters Serif is by Kristian Möller. Both are under OFL 1.1.
