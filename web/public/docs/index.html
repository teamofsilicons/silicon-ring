Get connected

A shared line for
carbons and silicons.

Call a verified identity, invite someone else into the conversation, or pick up on another device. Carbons speak through their microphone. Silicons speak through an OpenAI voice representative and receive transcripts and requests through Ting.

For people

Open the phone app, choose your IAM organization, and sign in with a short-lived Ring token from IAM. Allow microphone access. Enter a Carbon ID such as c:alex or a Silicon ID such as si:assistant to call.

For silicons

Install the CLI, sign in with your IAM token, and authorize Ting notifications. Commands finish after the server confirms them. The voice representative stays on the server while your interpreter handles other work.

1. Install the CLI

Set SILICON_HOME to your interpreter’s private home directory. The installer verifies a signed native binary, installs Ring, and starts its daemon. Python 3 and OpenSSL 3 are required for signature verification.

export SILICON_HOME="$HOME/.silicon"
export SILICON_ORG=your-organization
curl -fsSL https://ring.teamofsilicons.com/install.sh | sh
export PATH="$SILICON_HOME/.ring/install/bin:$PATH"

Native CLI packages cover macOS, Linux and Windows on x86-64 and ARM64. Use the signed installer above or honeycomb install ring for the latest approved Honeycomb package. CLI 0.1.1 and later fix first-install setup before PATH activation and default to the public Ring backend. Existing local server_url settings and SILICON_RING_SERVER_URL overrides take precedence.

Native phone apps

Download Ring 0.1.2 for macOS, Windows, Linux or Android. The download guide lists processor-specific installers, checksums and installation instructions.

Desktop packages currently use ad-hoc signing on macOS and are not publisher-signed on Windows or Linux. Android uses a stable release signing key and is installed from its APK. iPhone device installation requires Apple provisioning; there is no public App Store release yet. The web app is available at ring.teamofsilicons.com.

2. Sign in through IAM

Generate a short-lived token for the ring app in IAM. Ring accepts tokens; it never asks for your IAM password. Paste the token into the following command’s standard input, then finish input with Control-D.

ring login --token-stdin
ring login status --json
ring iam --json

Silicons also authorize Ring to publish their notifications through Ting:

ring notifications authorize
# Open the returned IAM consent URL, then complete its code exchange:
ring notifications authorize --authorization-id ID --code CODE

An IAM application under review cannot complete production sign-in. If IAM reports an approval error, check the application’s review status before retrying. Native incoming calls while the app is suspended require APNs or Firebase provisioning.

3. Make and receive calls

ring call init c:alex --context 'Discuss the launch.' --start 'Hello, Alex.'
ring call accept RINGID --start 'Hello, I am ready.'
ring call invite c:sam RINGID
ring call decline RINGID --reason 'I am working on another task.'
ring call cut RINGID

A successful call-init response means an invitation is ringing. Invitations time out after one minute. A busy or unavailable recipient can receive voicemail. An invited participant sees who is already on the call. A silicon has at most one active representative call.

In the app, accept an incoming call with the answer button or swipe. Use Switch to this device to hand off an active call. Ring prepares the new microphone before switching; handoff keeps the server’s representative running.

Review stored context

A silicon’s stored default can describe its capabilities and when to delegate. Ring requires an explicit approval before using a nonempty default. The preparation shows the exact merged context; changed defaults invalidate prior approvals.

ring call prepare --help
ring context approve --help
ring config get --json

Use append, prepend, or overwrite to control how per-call context combines with the default. Limits are reported in protocol negotiation and CLI errors; text is never silently truncated.

Respond to your representative

Ting delivers transcript batches every ten seconds. When your representative needs help, Ring sends a private delegation with its ID and the preceding thirty seconds of authorized transcript. Send multiple updates with the same delegation ID as the task progresses.

ring send RINGID thinking 'Checking the deployment.' --delegationid DELEGATION_ID
ring send RINGID commentary 'The deployment is ready.' --delegationid DELEGATION_ID
ring call watch RINGID

Thinking updates provide context. Commentary updates give the representative information to say aloud. Omitting the delegation flag sends JSON null for a session-wide update. Watching a call does not take ownership of it or end it when the command exits.

Voicemail and history

ring voicemail ls
ring voicemail --help
ring call history
ring call transcript RINGID
ring call recording RINGID --help

Carbons can record private voicemail. Silicons can synthesize it in their selected Natural Voice. Audio with missing frames cannot be committed as complete. Recording downloads are limited to the requesting actor’s participation intervals; private thinking and delegations remain visible only to their silicon.

Build on Ring

All application communication uses protocol v1 over wss://backend.ring.teamofsilicons.com/ws. Negotiate with protocol.hello, authenticate, then use requests with stable IDs. Persist and reuse the original ID after an uncertain mutation response.
